| Code | File Mode        | Open At   | Create File | Overwrite File |
| ---- | ---------------- | --------- | ----------- | -------------- |
| `r`  | Read-Only        | Beginning | ❌          | ❌             |
| `r+` | Read and Write   | Beginning | ❌          | ❌             |
| `w`  | Write-Only       | Beginning | ✅          | ✅             |
| `w+` | Write and Read   | Beginning | ✅          | ✅             |
| `a`  | Append-Only      | End       | ✅          | ❌             |
| `a+` | Append and Read  | End       | ✅          | ❌             |
| `x`  | Exclusive Create | Beginning | ✅          | ❌             |
