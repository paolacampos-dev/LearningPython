# Data Types

There are several data types in Python.
To identify the data type we use the type built-in function.

Strings
Number data types in Python:

- Integers - **int**: Integer(negative, zero and positive) = -3, -2, -1, 0, 1, 2, 3 ...
- Floating Point Numbers(Decimal numbers) - **float** = -3.5, -2.25, -1.0, 0.0, 1.1, 2.2, 3.5 ...
- Complex Numbers = 1 + j, 2 + 4j, 1 - 1j

- boleans: true or false
- but also truthy and falsy:
  - **Falsy**:
    False
    0
    0.0
    ""
    []
    {}
    None

  - **Truthy**: non empthy or non zero values are truthy
    1
    "Hello"
    [1, 2]
    {"name": "Ana"}

All those are fundamental data types (can't be broken into a smaller values of a different type)
Unlike a compound data type, which are known as data struct

any() --> if any of all has a true value #True if not is false
all() --> all true # true if not false
