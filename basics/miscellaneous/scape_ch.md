# Back Slash End "\":

| Character | Meaning                            |
| --------- | ---------------------------------- |
| `\n`      | Newline                            |
| `\t`      | Tab                                |
| `\a`      | ASCII Bell                         |
| `\ooo`    | Character with octal value `"ooo"` |
| `\xhh`    | Character with hex value `"hh"`    |
| `\\`      | Backslash                          |
| `\"`      | Double quote                       |
| `\'`      | Single quote                       |
| `\b`      | Backspace                          |
| `\r`      | Carriage return                    |
