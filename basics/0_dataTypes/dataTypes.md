# Data Types

There are several data types in Python.
To identify the data type we use the type built-in function.

Number data types in Python:

Integers - **int**: Integer(negative, zero and positive) = -3, -2, -1, 0, 1, 2, 3 ...
Floating Point Numbers(Decimal numbers) - **float** = -3.5, -2.25, -1.0, 0.0, 1.1, 2.2, 3.5 ...
Complex Numbers = 1 + j, 2 + 4j, 1 - 1j
